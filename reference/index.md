# Package index

## Hero function

- [`enrich_volcano()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/enrich_volcano.md)
  : Build a composite volcano + enrichment ring plot

## Pipeline steps

- [`ev_validate()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ev_validate.md)
  : Validate and canonicalize input from any supported source
- [`pi_score()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/pi_score.md)
  : Compute pi-score (Xiao 2014)
- [`adjust_p()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/adjust_p.md)
  : Adjust p-values
- [`ev_enrich()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ev_enrich.md)
  : Run enrichment (fgsea + ORA) against one or many databases
- [`ev_collapse()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ev_collapse.md)
  : Deduplicate enrichment results
- [`ev_volcano()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ev_volcano.md)
  : Build a volcano ggplot for one contrast
- [`ring_plot()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ring_plot.md)
  : Build an enrichment ring ggplot for one contrast
- [`ev_compose()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ev_compose.md)
  : Compose volcano and ring panels into a patchwork

## Databases

- [`list_databases()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/list_databases.md)
  : List supported gene-set databases
- [`database_info()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/database_info.md)
  : Print extended description for one database

## Styling

- [`ev_theme()`](https://Dustyn-T-Lewis.github.io/enrichVolcano/reference/ev_theme.md)
  : enrichVolcano theme and palette
